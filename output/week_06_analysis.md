# TOOLING NOTE

- **Jaguars and Commanders games were silently missing from games to watch.** `TEAM_ALIASES` in
  `analyze.py` mapped `JAX → JAC` and `WAS → WSH`, but nflverse spells them **JAX** and **WAS**.
  `analyze.py` was unaffected because it tries both spellings. `find_games.py` uses only the
  alias, so HOU @ JAX (Little, Lawrence, Thomas) was dropped from this week's file until the two
  entries were removed and the report regenerated. This also affected every earlier week a JAX
  player was rostered. The `analyze.py` fix is local and **not committed** with this file.
- **PPG is full-PPR, and the league is half-PPR.** The stat lines read
  `fantasy_points_ppr_per_game`, so high-volume pass catchers (Nacua, London) look slightly better
  than they score here.
